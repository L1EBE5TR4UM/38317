상단 우측에서 A / B / C / D TYPE을 전환할 수 있어요.
A TYPE = 자막 + Play/EQ 바 표시 (서사 로그 / 스토리 게시용)
B TYPE = Prompt·Model·Info 메타 바 표시 (봇 카탈로그 / 캐릭터 소개용)
C TYPE = 매거진 커버 (히어로 이미지 표지 + 큰 제목 + 캐릭터명·소제목)
D TYPE = 투명 배경 인물 소개 헤더 (USER/CHAR 2인 + INTRODUCTION)
